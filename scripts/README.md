# Scripts

Utility scripts for local development and verification.

## Available Scripts
- `bootstrap.sh`: create `.venv`, install backend dependencies, and install frontend dependencies
- `dev-backend.sh`: start the PR review backend service on `127.0.0.1:8000`
- `dev-static.sh`: start the same backend service for the built-in static console entry on `/`
- `dev-frontend.sh`: start the Vite development server on `127.0.0.1:5173`
- `verify.sh`: run the local backend/frontend verification flow
