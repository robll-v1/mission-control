# MVP Scope

## In Scope
- Single-user local workflow
- Single agent backend
- GitHub issue ingestion
- Task list and mission detail pages
- Live event timeline and log stream
- Changed files, diff, and summary artifacts
- Repo-configured validation commands

## Out of Scope
- Multi-agent orchestration
- Team collaboration features
- Cloud hosting
- Automatic reviewer voting loops
- Complex permission systems

## Success Criteria
- A real issue URL can create a task
- The agent run is visible in real time
- Failures are diagnosable from timeline/logs
- Validation results are persisted and visible
- A human can decide whether to retry, abort, or accept the output
