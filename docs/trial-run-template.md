# Agent Mission Control 真实 Issue 试跑模板

这个模板用于验证 `issue -> context -> opencode -> timeline -> validation` 这条主链路是否真的成立。

目标不是“刷成功率”，而是判断：
- AMC 现在到底有没有真实价值
- 是 `context` 问题、`opencode` 问题，还是验证链路问题
- 下一步最该补什么

## 四、第一轮 Issue 选择建议

建议按下面组合来：

### Issue 1：文档 / 测试补充
用于验证：
- issue 抓取是否稳定
- context 编译是否合理
- timeline 是否清晰

### Issue 2：小 bug 修复
用于验证：
- candidate files 是否准
- `opencode` 是否能进入正确代码区域
- 首轮自动结果是否可用

### Issue 3：中等逻辑改动
用于验证：
- repo 理解能力
- context compiler 的边界
- 当前验证链是否够用

---

## 五、试跑时最该盯的 5 个点

1. `context/context.md` 到底有没有用
2. candidate files 准不准
3. timeline 是否能帮你快速诊断问题
4. 失败时能不能快速归因
5. 你愿不愿意再用第二次
